# Code of Conduct

PlaceGap follows the Contributor Covenant Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background or identity.

## Expected behavior

- Be respectful and specific.
- Critique claims, evidence, schemas, and code, not people.
- Distinguish disagreement from misconduct.
- Prefer reproducible examples over rhetorical certainty.
- Correct errors openly.

## Enforcement

Project maintainers are responsible for clarifying and enforcing acceptable behavior and may remove, edit, or reject contributions that violate this code.

This document is adapted from the Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
