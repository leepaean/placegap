# Diagnostic Framework

PlaceGap uses eight dimensions as diagnostic coordinates:

1. RESOURCE — what assets and capabilities actually exist?
2. MEANING — have they been organized into intelligible and distinctive place meaning?
3. VISIBILITY — can relevant audiences see and correctly understand that meaning?
4. EXPERIENCE — can visitors or participants actually perceive and engage with it on site?
5. PRODUCT — has value been translated into participatory, usable, purchasable, or repeatable forms?
6. CONVERSION — does this create actual value such as time, spending, participation, employment, or commitment?
7. ADVOCACY — does it generate recommendation, UGC, return visits, or external propagation?
8. REGENERATION — can the place continue producing new culture, products, participants, and reasons to return?

A Gap is a suspected structural relationship between dimensions. It is not automatically a fact or a score.
