# Roadmap

## v0.0.x — bootstrap

- Freeze domain language
- Define evidence discipline
- Establish validation cases
- Build the first API vertical slice

## v0.1.0 — diagnostic prototype

- Evidence Board
- Human Finding verification
- Gap candidates
- Hypothesis Inspector
- Contradiction and Evidence Need handling
- Markdown / JSON export
- Blind comparison against ordinary and expert-prompt GPT analysis

## Only after v0.1 validation

Potential directions include evidence-change invalidation, UGC analysis, open geographic data connectors, longitudinal diagnosis, team collaboration, MCP, monitoring, benchmarking, Opportunity Maps, and strategy generation.

Nothing beyond v0.1 is committed until the product passes its kill/go experiment.
