# v0.1 User Stories

## Consultant

As a place-based consultant, I want every important diagnosis to show its supporting and contradicting evidence so I can defend or revise it later.

## Planner

As a planner, I want to separate observed conditions from interpretations so project strategy is not built on hidden assumptions.

## Cultural operator

As a cultural-place operator, I want the system to tell me when available evidence cannot yet distinguish between competing bottlenecks.

## Researcher

As a researcher, I want an exported diagnostic state to preserve source references, uncertainty, and alternative explanations rather than only a polished report.
