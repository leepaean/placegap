# Validation Rules

A proposed diagnostic result fails validation if it:

- states a Hypothesis as a direct fact;
- cites Evidence that does not actually support the Finding;
- ignores known contradicting Evidence;
- assigns HIGH confidence despite unresolved major contradictions;
- turns missing evidence into a negative score;
- recommends an intervention before the diagnostic question is adequately framed.

These rules should eventually be executable as diagnostic audits where possible.
