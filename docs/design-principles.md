# Design Principles

1. Evidence before advice.
2. Hypothesis before strategy.
3. Unknown before hallucination.
4. Diagnosis before intervention.
5. Contradiction is first-class data.
6. Human review changes state, not just presentation.
7. Source absence is not poor performance.
8. Place value is plural; economic conversion is not the only legitimate outcome.
9. The system should expose uncertainty instead of decorating it.
10. A narrow verified workflow beats a broad impressive demo.
