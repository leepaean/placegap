# Human Review

AI-generated diagnostic objects are proposals.

## Findings

A reviewer can:

- ACCEPT — statement is supportable as written;
- EDIT — preserve the generated statement and store a reviewed version;
- REJECT — retain the rejected object for audit history.

## Hypotheses

A reviewer should inspect supporting evidence, contradicting evidence, missing evidence, alternative explanations, and confidence before accepting a hypothesis.

Human review is not ceremonial approval. It is part of the data model.
