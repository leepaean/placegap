# MVP Acceptance Criteria

PlaceGap v0.1.0 is not ready until a user can:

- create a Place with explicit diagnostic scope;
- add and edit Evidence with source provenance;
- create or generate atomic Findings tied to Evidence;
- accept, edit, or reject Findings;
- create Gap candidates and Hypotheses;
- attach supporting and contradicting Evidence;
- record missing Evidence and alternative explanations;
- use HIGH/MEDIUM/LOW/UNKNOWN confidence only;
- export a traceable diagnostic state to Markdown and JSON;
- run all three validation cases through the same protocol.

The product-level blind comparison must then determine whether to continue or kill the project.
