# PlaceGap Methodology

## The problem

Generic LLM analysis tends to collapse several epistemic layers:

1. source material;
2. directly supportable observation;
3. interpretation;
4. diagnosis;
5. recommendation.

PlaceGap keeps them separate.

## Core rule

A source is not a Finding.  
A Finding is not a Hypothesis.  
A Hypothesis is not a fact.

## Diagnostic dimensions

- RESOURCE
- MEANING
- VISIBILITY
- EXPERIENCE
- PRODUCT
- CONVERSION
- ADVOCACY
- REGENERATION

These are diagnostic coordinates. PlaceGap does not assume that every place follows a single linear funnel.

## Confidence

v0.1 intentionally avoids numerical confidence.

- HIGH
- MEDIUM
- LOW
- UNKNOWN

A model may suggest confidence, but a human reviewer owns the final state.

## Unknowns

`Insufficient evidence` is a valid and desirable diagnostic output.

The tool should prefer a useful unknown over a fabricated conclusion.
