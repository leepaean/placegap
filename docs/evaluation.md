# Product Validation Protocol

PlaceGap must beat a good prompt for reasons that require software.

## Cases

1. Qianfoyan / 千佛岩
2. Hanyang Ancient Town / 汉阳古镇
3. Taoxichuan / 陶溪川

## Conditions

- A: ordinary GPT analysis
- B: strong expert prompt
- C: PlaceGap

All conditions receive the same source pack.

## Blind evaluation metrics

- Non-obviousness
- Evidence fidelity
- Uncertainty discipline
- Counter-evidence handling
- Alternative explanations
- Decision relevance
- Traceability

## Kill rule

Kill or redesign the product if PlaceGap's advantage is explainable only by having a better prompt or prettier output.

## Go rule

Continue if the software reliably preserves diagnostic state across time, evidence changes, human edits, contradictions, and uncertainty.
