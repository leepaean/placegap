# Maintenance Principles

PlaceGap's maintenance record should reflect real product learning.

- Keep Issues tied to specific diagnostic or engineering failures.
- Close Issues with evidence of completion, not vague status updates.
- Prefer narrow pull requests.
- Record meaningful methodology changes in the Decision Log.
- Do not manufacture activity metrics for appearances.
- Releases should correspond to usable increments.

The project is being built to become useful first. OSS credibility should emerge from that work rather than become a separate performance.
