# v0.1 Product Scope

PlaceGap v0.1 exists to test one proposition:

> Can a structured diagnostic system produce more auditable place diagnoses than an expert prompt alone?

## In scope

- Place creation and diagnostic scope
- Evidence entry and provenance
- Atomic Findings
- Human Accept / Edit / Reject
- Gap candidates
- Hypotheses
- Supporting and contradicting evidence
- Missing evidence
- Alternative explanations
- Qualitative confidence
- Markdown / JSON export

## Out of scope

- automatic strategy generation
- tourism marketing copy
- social-media scraping
- destination scoring
- GIS dashboards
- multi-agent orchestration
- investment modelling
- commercial SaaS features

If a proposed feature does not help validate the core proposition, it waits.
