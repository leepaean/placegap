# Source Types

Initial Evidence source types:

- `official`
- `statistics`
- `academic`
- `media`
- `operator`
- `visitor_review`
- `field_observation`
- `interview`
- `planning_document`
- `other`

Source type is not the same as reliability. An official source may be authoritative for visitor counts but weak evidence for visitor experience. Reliability must be interpreted in relation to the claim being supported.
