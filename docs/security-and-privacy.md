# Security and Privacy

PlaceGap is local-first in v0.1.

- Uploaded working files should remain in the user's local workspace.
- API keys belong in `.env`, which is ignored by Git.
- No account system or cloud synchronization is required for v0.1.
- Diagnostic exports may contain sensitive research or project information and should be handled accordingly.
- External LLM calls, when introduced, must be explicit so users know which content leaves the local environment.
