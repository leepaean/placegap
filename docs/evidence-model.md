# Evidence Model

Every significant diagnostic claim should remain traceable to evidence.

## Evidence

Evidence stores source metadata and an excerpt or datum. It must not silently contain an AI interpretation.

## Finding

A Finding is atomic and directly supportable by one or more evidence items.

Good:

> The official source reports 80,000 visitors during the holiday period.

Bad:

> Visitor awareness is not a problem.

The second statement is a hypothesis.

## Contradiction

Contradicting evidence is first-class data. It should not be buried in notes.

## Evidence Need

When evidence is insufficient, create an Evidence Need instead of forcing a diagnosis.
