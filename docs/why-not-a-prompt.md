# Why Not Just Use a Better Prompt?

This question is PlaceGap's core product challenge.

If an expert prompt can provide the same durable value, PlaceGap should not exist as software.

Software becomes justified only if users benefit from persistent diagnostic state that a prompt alone does not reliably manage, including:

- stable evidence identifiers;
- human verification history;
- explicit contradictions;
- unresolved Evidence Needs;
- competing hypotheses;
- changes to diagnosis when new evidence arrives;
- reproducible export and comparison over time.

The v0.1 evaluation protocol exists to test this claim rather than assume it.
